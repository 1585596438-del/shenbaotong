# 聊天界面与独立会话验收

2026-10-07按用户要求，将申报通问答页改为类似DeepSeek的浅色聊天布局，保留申报通名称和原文引用。新建聊天指页面内独立会话，可通过侧栏切换，不启动额外浏览器窗口。沿用每阶段提交PR并合并到现有默认分支的授权。

会话与消息关联增量保存到SQLite，原answers正文及知识库表不改写。首次迁移把全部旧问答一次性关联“历史聊天”；迁移和保存关联在事务中完成。消息保存独立顺序号，同一毫秒产生的消息也保持顺序。每个会话自动采用第一问作标题、保存成功提问的资料范围；详情读取全部消息，无30条截断。新聊天上下文为空，追问只取本会话最后一条；跨会话previousAnswerId在调用模型前拒绝。

问答页采用淡灰侧栏、蓝色操作按钮、居中欢迎内容、右侧用户气泡与左侧助手消息、底部圆角输入框。原文面板默认收起，点击消息依据再展开；资料范围从输入框入口打开。支持Enter发送、Shift+Enter换行、中文输入法确认保护、等待状态、失败保留输入、切换时暂存未发送草稿。刷新恢复会话及已保存消息，未发送文本不跨刷新保存。手机会话和范围位于抽屉侧栏，提供关闭、Escape和焦点保护。

验证：npm test为95/95通过，npm run typecheck及npm run build成功。五项新增测试使用临时库，覆盖旧库迁移正文不变且重启不重复、35条完整历史及同毫秒顺序、独立会话与跨会话上下文拒绝、不存在会话不写答案、来源删除级联清理及资料范围过滤、真实Request建档/详情/404/外站写入保护。其余90项规则、问答和抓取回归通过。

实际生产浏览器使用artifacts/chat-validation/data知识库副本，临时禁用模型调用，不修改.env.local。页面发送软件杯问题及连续追问，消息数从1变2；打开24条原文依据。新聊天为空白且范围为全部资料，在另一会话发送蓝桥杯问题，返回软件杯仅有该会话两条消息并恢复未发送草稿；刷新恢复当前会话及两条消息。注入问题请求400后显示可读错误，输入两行文字不丢失且无成功消息。Shift+Enter实际保留换行，没有发送。

1440×1000桌面欢迎页/消息页，以及390×844手机欢迎页/消息页/侧栏截图均已实际查看。聊天页面scrollWidth分别1440、390，无横向溢出；手机输入框位于视口内。资料库仍展示22份资料，规则库仍展示3项已发布赛道，浏览器未报告运行错误。

最后补齐手机侧栏键盘保护后，重跑类型检查及生产构建，均成功；重启验收服务后会话仍在。实际打开侧栏焦点进入关闭按钮，Shift+Tab仍留在侧栏，Escape关闭并恢复菜单按钮焦点；点击当前会话亦关闭侧栏。正式网页HTTP为200并含新聊天输入框。

正式库只进行增量迁移，不发送测试问题。83条旧问答全部关联一个历史会话；逐行比较原资料、片段、赛事、赛道、版本与依据，与验收副本一致，83条旧问答正文亦逐行一致。副本产生的验收会话、截图、辅助脚本与数据库均在忽略目录，不上传。最终网页保留运行在http://127.0.0.1:3000，使用原有模型配置；验收服务关闭。

本轮实现聊天布局与持久会话，不增加模型产品功能。旧无sessionId的问题接口仍可用于原有调用；这些调用保留旧全局问答行为，不自动归属新会话。未实现流式输出、聊天删除或重命名。阶段PR在提交后记录。
