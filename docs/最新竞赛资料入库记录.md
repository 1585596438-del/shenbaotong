## 本地数据与复用

实际原文和数据库存放在被 Git 忽略的 `data/` 目录，GitHub 提交保存导入脚本、来源清单和本记录。另一台电脑仅拉取代码不会得到这些资料；需要持有相应本地快照和数据库。完整原文、数据库、备份、模型配置和用户聊天不上传仓库。

`npm run sources:import -- --dry-run` 核对默认清单，不写入。`npm run sources:import` 导入已复核快照，也可在 `--` 后指定其他清单文件。全部快照须先通过来源网址、正文 SHA-256、年度依据、页序和分块校验。写入前通过 SQLite 一致性备份保存现有知识库到 `data/backups/`；同一正文及来源、年度、阶段、类型、赛事元数据重复导入不会新增文档。备份失败会停止导入，实际结果存入 `data/latest-competition-import-report.json`。

资料入库后立即可用关键词检索；本轮未调用外部模型做向量索引，未自动发布新的结构化赛事规则。同步修复了完整赛事名称反复出现在介绍中时挤掉具体条款的问题：名称先限定来源，再补检用户询问的条件，并去掉重复片段。保留原始问题和年度筛选。
